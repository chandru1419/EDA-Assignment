## Project Overview
This project explores historical Google (GOOGL) stock market data using Exploratory Data Analysis (EDA), statistical summaries, and data visualization. An LSTM neural network is used to experiment with next-day closing-price forecasting.

## Objectives
- Explore historical stock prices and trading volume.
- Perform data cleaning and preprocessing.
- Visualize price trends, daily returns, moving averages, and correlations.
- Build and evaluate an LSTM forecasting model.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- TensorFlow / Keras
- yfinance

## Dataset
Source: [Yahoo Finance — GOOGL Historical Data](https://finance.yahoo.com/quote/GOOGL/history/)

The Python script downloads the historical data when executed. Results depend on the data available at runtime.

## How to Run
1. Install Python.
2. Install the dependencies listed in `requirements.txt`.
3. Run `python Google_Stock_EDA_LSTM.py`.
4. Review the generated visualizations and evaluation metrics.

## Model Evaluation
The model is evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and Mean Absolute Percentage Error (MAPE). Actual metrics should be added after running the code.
